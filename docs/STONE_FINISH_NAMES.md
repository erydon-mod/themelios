# Stone finish names

Ganosis is the mirror finish. Stone names follow ERYDON's captured active stone
settings when its compatible client settings API is installed: `(Honed)`,
`(Polished)` or `(Ganosis)`. Plain stone, Herringbone, Weave and inlay substrates
use their respective per-material settings, including pattern overrides. Metal
names and fixed aged, ashlar, hewn, rusticated and Rock finishes remain unchanged.

Changes require restarting, like the renderer setting itself. Without a
compatible ERYDON settings API, Themelios retains its original authored names;
ERYDON is still optional. Names are supplied by a language-only overlay, which
never opens or replaces resource-pack textures. Existing `mirror` configuration
and legacy search spellings remain compatible; no block or item IDs change.
