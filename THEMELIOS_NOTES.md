# ERYDON Themelios Notes

This project is the small, basic-shapes jar for ERYDON.

Current choice:
- Include simple and medium block types.
- Exclude pendant halo because it is only a helper.
- Exclude brazier and oil burner because they are not building blocks.
- Exclude all glazing and framed glazing.
- Exclude complex auto-layout blocks for now.

Reminder for later:
- We may add simple replacement blocks for some complex ERYDON blocks.
- Keep the mod id and block namespace as `themelios`.
- Themelios can be loaded beside the main `erydon` mod and Daedalon.
- Keep shared texture references compatible with the native 16x resources and the unified 32x/64x packs.
